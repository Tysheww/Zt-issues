# 🏙️ Zhytomyr Issues

Веб-додаток для фіксації, публікації та відстеження міських проблем міста Житомир. Проєкт створений для того, щоб небайдужі громадяни могли зручно повідомляти про інфраструктурні проблеми міста.

## 🚀 Основний функціонал

* **Авторизація:** Реєстрація та вхід користувачів за допомогою електронної пошти та пароля.
* **Публікація:** Можливість додавати нові звернення або проблеми.
* **Синхронізація:** Збереження та відображення даних у реальному часі завдяки інтеграції з хмарною базою даних.

## 🛠️ Стек технологій

* **HTML5 & CSS3** — структура та візуальне оформлення (інтерфейс).
* **Vanilla JavaScript** — логіка роботи додатку без використання важких фреймворків.
* **Firebase** — використання платформи від Google для бекенду:
    * *Firebase Authentication* — безпечна система входу.
    * *Firebase Database / Firestore* — зберігання інформації про звернення.
